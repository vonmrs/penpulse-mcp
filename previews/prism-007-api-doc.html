API Reference

OpenAI Chat Completions

POST https://api.openai.com/v1/chat/completions

// 请求参数

string model // 模型名称，如 gpt-4o

array messages // 对话消息列表

number temperature // 采样温度，0-2，默认0.7

integer max_tokens // 最大生成token数

stream stream // 是否启用流式输出，默认 false

// 响应示例

{'id': 'chatcmpl-abc123',

'model': 'gpt-4o',

'choices': [{'message': {'role': 'assistant',

'content': 'Hello!'}, 'finish_reason': 'stop'}]}

// 关键说明

→ messages 数组最后一条必须是 user 或 system 角色

→ temperature 越高回答越随机，0.3-0.7适合大多数场景

→ max_tokens 限制的是单次回复，不是整个会话
